# YouTube Time Guard

A browser extension that helps you spend less time on YouTube by hiding Shorts and setting viewing limits.

Designed for desktop Chrome and Firefox, with support for Chromium-based browsers planned.

> Under development. The extension's build foundation is available; the features below are not implemented yet.

## Planned features

- **Hide Shorts** — remove Shorts cards, shelves, and navigation, and redirect Shorts links to the YouTube home page.
- **Limit viewing time** — set a shared time budget for videos, live streams, and Shorts, followed by a configurable cooldown.
- **Limit unique Shorts** — choose how many different Shorts to watch per cycle, with a separate recovery period.
- **Keep control** — configure limits independently and see remaining budgets in the extension popup.
- **Stay local** — no account, server, analytics, or cross-device synchronization.

Built with [WXT](https://wxt.dev/), TypeScript, and plain HTML/CSS.
